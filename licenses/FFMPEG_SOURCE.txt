WRITTEN OFFER OF SOURCE — FFmpeg and its GPL dependencies
==========================================================

Sieve for Android bundles a self-built FFmpeg executable (packaged as
libsieveffmpeg.so and executed as a child process) statically linked with
x264, x265, LAME (libmp3lame), Opus (libopus), libvpx (VP9), SVT-AV1 and libwebp.
FFmpeg is built with --enable-gpl --enable-version3, so the binary is licensed
under the GNU General Public License, version 3 (see licenses/GPL.txt in this
repository and the app's About screen).

Corresponding source
--------------------
The complete corresponding source for the bundled FFmpeg and its dependencies
is the exact upstream commit or release tarball of each project listed below,
plus the build recipe in transcode/build-ffmpeg/ffbuild.sh in this repository.
All are unmodified upstream sources (no local patches).

Toolchain: Android NDK r27.3.13750724, minSdk API 26.
ABIs built: arm64-v8a (device), x86_64 (emulator).

Exact FFmpeg configure line
---------------------------
  ./configure \
    --prefix=<out> \
    --target-os=android --arch=<aarch64|x86_64> --enable-cross-compile \
    --cc=<clang> --cxx=<clang++> --ar=llvm-ar --ranlib=llvm-ranlib \
    --strip=llvm-strip --nm=llvm-nm --sysroot=<ndk-sysroot> \
    --pkg-config=pkg-config --pkg-config-flags=--static \
    --extra-cflags="-I<deps>/include -O2 -fPIC -fPIE" \
    --extra-ldflags="-L<deps>/lib -pie -static-libstdc++ -Wl,-z,max-page-size=16384" \
    --extra-libs="-lm" \
    --enable-gpl --enable-version3 \
    --enable-libx264 --enable-libx265 \
    --enable-libmp3lame --enable-libopus --enable-libvpx --enable-libsvtav1 --enable-libwebp \
    --enable-jni --enable-mediacodec \
    --disable-shared --enable-static \
    --disable-doc --disable-ffplay --disable-ffprobe \
    --enable-ffmpeg

Each dependency is built as a static, position-independent library for API 26
with the same NDK toolchain (libvpx is configured with --enable-vp9
--disable-vp8 --enable-pic --disable-examples --disable-tools --disable-docs
--disable-unit-tests; SVT-AV1 and libwebp are built with CMake using the NDK's
android.toolchain.cmake; the exact options are in ffbuild.sh).

To rebuild: run `bash transcode/build-ffmpeg/ffbuild.sh all` on a Linux host
with the NDK at /opt/android-sdk/ndk/27.3.13750724 (override with NDK=...; set
FF_ROOT=<dir> for a writable build directory). The script fetches the exact
commits and tarballs above (checking each tarball's SHA-256), applies the NDK
libc++ pkg-config fix to x265.pc, and verifies 16KB LOAD alignment and the
presence of every --enable-lib* flag before emitting each ABI's
libsieveffmpeg.so.
